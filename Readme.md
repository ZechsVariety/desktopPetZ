### What is it?



DesktopPet Z is a fork of [desktopPet by Adriano](https://github.com/Adrianotiger/desktopPet). It's my custom build for fun tests and experiments, and it includes [all my custom pets](https://github.com/ZechsVariety/Zechs-Desktop-Pets).



This fork is purely for fun, but I also turn any successful experiments (that could benefit the vanilla app) into [separate branches](https://github.com/ZechsVariety/desktopPetZ/branches), and then create pull requests with them.
